OUTPLAY - הפעלת רישוי מאמנים
=============================
1. ב-Render: Environment -> Add Variable
   COACH_CODES = AVI2026:Avi Cohen,DANA77:Dana Levi
   (קוד:שם, מופרדים בפסיק. בלי המשתנה הזה האתר פתוח כמו עכשיו.)
2. SECRET = מחרוזת אקראית ארוכה (כדי שהכניסות לא יתאפסו כשהשרת עולה מחדש)
3. אופציונלי: MAX_ROOMS_PER_COACH = 5 (מספר חדרים פעילים למאמן)
4. מאמן חדש = שורה חדשה ב-COACH_CODES. הפסקת מנוי = מחיקת הקוד ושמירה (נכנס לתוקף מיד).
שחקנים לא צריכים רישיון: הם נכנסים עם קישור/קוד חדר של המאמן.
